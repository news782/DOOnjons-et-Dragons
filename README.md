# 📂 DOOnjon&Dragon Project
Application Java simplifiée inspirée du jeu de rôle Donjons & Dragons, où les joueurs affrontent des monstres dans plusieurs donjons successifs.

## 🌟 À propos du Projet
Ce projet est un jeu de rôle simplifié en Java. Les joueurs créent des personnages et parcourent des donjons (en affrontant des monstres) afin de tenter de terminer la partie en complétant les différents donjons.
Un Maître du Jeu est désigné parmi les joueurs pour choisir les monstres et les placer sur la carte.

Pour jouer, il suffit de lancer le main : tout se déroule dans le terminal.

## 🚀 Démarrage Rapide

Pour pouvoir exécuter et tester l'application sur votre machine :

### Prérequis
* Java 17+ (ou version compatible)
* IDE Java (IntelliJ, Eclipse, NetBeans, etc.)
* Git

### Exécution

1.  **Cloner le dépôt :**
    ```bash
    git clone https://github.com/news782/DOOnjons-et-Dragons.git
    ```
  
2. Ouvrez le projet dans votre IDE

3. Compilez le projet (`src/` contient `Main.java` et toutes les classes)

4. Lancez l'application avec la classe `Main`
